# محفظتي العقارية — نظام إدارة محفظة عقارية مؤجرة

يعمل محليًا على XAMPP (PHP + MySQL) بواجهة عربية.

## التشغيل
1. انسخ مجلد `rp` إلى `C:\xampp\htdocs\`.
2. شغّل Apache وMySQL من لوحة XAMPP.
3. افتح: http://localhost/rp/

تُنشأ قاعدة البيانات `rp_portfolio` وجداولها تلقائيًا عند أول تشغيل. إذا لم تكن MySQL متاحة يعمل النظام احتياطيًا على SQLite في `data/rp.sqlite`.

## الملفات
- `index.html` + `assets/` — الواجهة.
- `api/index.php` — REST API (`?r=properties`, `?r=contracts/5/renew`, `?r=reports/pnl` …).
- `api/db.php` — الاتصال والتثبيت التلقائي للجداول.
- `api/logic.php` — الاستحقاقات، التحصيل، الإحصائيات، التقارير، البيانات التجريبية.
- `api/assistant.php` — المساعد الذكي (محلي، أو عبر Anthropic API عند وضع مفتاح في `api/config.php`).

## استيراد بيانات النسخة V2
من صفحة V2 القديمة: التقارير → تصدير JSON، ثم في النظام الجديد: الإعدادات → استيراد من النسخة V2.
